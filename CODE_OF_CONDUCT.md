# Code of Conduct

Forge follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion about the
work. Harassment of any kind isn't tolerated.

Report unacceptable behaviour to **arpitkohale2@gmail.com**. All reports are
handled privately.
